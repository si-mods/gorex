# What to Test

A build's What to Test, per locale, is what its locale section here gained
since the last build that uploaded: `ios/scripts/test-notes` sets `en-US`
from `## en-US` and `zh-Hans` from `## zh-Hans`.

A pull request that changes what a tester sees adds one bullet to each
section, in the app's terms: what they get to try, not how it is built. A
bullet that reads like a commit subject is one testers cannot read, and the
`web` job of `.github/workflows/ci.yml` fails it.

- 点麦克风时，应用不再在麦克风启动期间卡住，听写时的音量条也更流畅。如果麦克风漏掉你开头说的话，或停止后仍在录音，请告诉我们。
- 标签很多时，主机列表打开和滚动更流畅；改动后，主机最近的项目会无卡顿地保存。如果主机离线时看不到它最近的项目，请告诉我们。
- 键盘弹出时，输出很多的终端更流畅，并且仍只上移到刚好露出光标所在行及其下方绘制的内容。如果需要的行被键盘挡住，请告诉我们。
- 「开发者模式」「记录键盘输入」以及拷贝版本、调试信息的按钮，从「关于」和「终端」里挪到了单独一页：「设置 › 开发者」。
- 把 Rex Go 的「动态」小组件添加到主屏幕或锁定屏幕：它显示智能体在等你处理的事。点一行即可打开对应终端。小组件在 Rex Go 打开时更新。
- 打开终端时离开 Rex Go：锁定屏幕和灵动岛会显示它的程序状态和最新的一行。连接会保持约 25 秒，之后显示为已暂停。
- 终端显示在灵动岛上时长按它：程序图标现在和标题、状态在同一行，不再被顶部的圆角切掉。
- 运行 Claude Code、Codex 等智能体时离开 Rex Go：锁定屏幕和灵动岛现在显示它正在做的事或它等你回答的问题，不再显示底部状态栏。
- Claude Code 或 Pi 工作时离开 Rex Go：锁定屏幕和灵动岛现在显示它自己报告正在做的事，完成后显示它最后做的事。
- 打开终端时离开 Rex Go，看锁定屏幕：卡片现在用大字显示程序正在做的事，背景是程序自己的颜色和图标。灵动岛不变。
- 锁定屏幕上的卡片现在用程序自己颜色的深浅两档，各种状态下大小不变，计时跟在状态后面，不再压在大图标上。
- 打开标签页、标题的面板、设置、新建项目或图库图片：它现在从你点按的地方展开，关闭时缩回原处。窗格栏的高亮会滑到你选的窗格。
- 从主机列表离开 Rex Go 后，几秒内需要你回答的程序现在也会发来通知，和从打开的终端离开时一样。
- 打开终端时从 Wi-Fi 切到蜂窝网络，或换一个 Wi-Fi：终端立即重新连接，从断开处继续，不再卡住一段时间。
- 点按列表中的标签页：终端又从右侧滑入，从左边缘轻扫即可滑回。打开或关闭终端时，列表保持它自己的浅色或深色外观。
- 终端底部的按键栏，第一页末尾现在有回车键；Tab 移到了最后一页。
- 重命名项目后，它未命名的窗口在列表里和终端标题栏也会显示项目的新名字。
- 每个项目现在有自己的卡片，用项目色的文件夹图块，箭头在标签数之前。「无项目」也是可折叠的卡片。项目列表里的程序图标在浅色页面上不再有白色圈。在 iPad 上，正在用的项目卡片会略深一些。
- 面板里的程序开始监听端口后，终端顶栏会出现一个地球按钮；点开能看到端口、地址和程序，能直连的端口可以直接在 Safari 打开。
- 在电脑列表中下拉刷新：手会感到一下轻点，所有未连接的电脑会立即重新连接。
- 在 Mac 上，「添加主机 › 手动设置」、主机详情、配对、「设置」和「编辑空间」不再让应用退出。
- 只在本机开放的网页现在能在手机上打开：在端口列表里点 127.0.0.1 端口旁的「在手机上打开」，同一 Wi-Fi 下 Safari 就会显示。
- 重命名标签页后，它打开的终端上方标题也会跟着改成新名字，不再只是列表里那一行更新。
- 项目卡片展开和收起现在有了和「无项目」一样的动画。
- 面板里只在本机开放的端口，在手机不在同一网络时会标明「Only on the host’s network」，不再显示点了会失败的「在手机上打开」。
- 手机休眠后连不上的已配对电脑，现在下一次连接就会走新通道，不再一直失败。
- 需要你填名字或做选择的操作（比如新建工作树）现在也会在手机上弹出提问：在手机上填写或取消，所有设备会一起关闭。
- 锁屏上的那行字和程序发来的通知会去掉转义码和画成方块的字符，中文和表情照常显示。
- 「添加主机 › 扫码配对」顶部新增照片按钮：选一张带有配对二维码的截图或照片，Rex Go 就能读取。
- 终端运行中离开应用：它的绘制现在会在应用挂起前彻底停下，不再可能在后台因图形问题被关掉。
- 终端运行中锁屏：绘制现在也会为锁屏快照停下。下拉控制中心只停一瞬，面板还开着时就恢复绘制。
